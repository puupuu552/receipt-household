# 生活費レシート管理 PWA v1.3.2.2

iPhoneのホーム画面から使う、端末内保存型の生活費レシート管理PWAです。

## v1.3.2.0
- レシートをiPhoneカメラで撮影 / 写真から選択
- Tesseract.jsによる日本語+英語の端末内OCR（試験版）
- OCR画像はIndexedDBへ保存しない
- 購入日・店舗・商品名・金額を読み取り、確認画面へ展開
- 食費 / お菓子・嗜好品 / 果物 / 野菜 / 日用品へ自動分類
- 不確かな商品はピンクの「要確認」
- 商品名・税込計上額・カテゴリを手動修正可能
- 商品の追加 / 削除
- 母向け / その他は手動指定のみ
- IndexedDB保存、月次集計、Excel出力
- アプリバージョン表示と「最新版を確認・更新」

## OCRについて
OCR処理そのものは端末内で行います。初回OCR時はTesseract.js本体と日本語OCRデータをインターネットから読み込みます。撮影画像そのものを外部OCR APIへ送信する実装ではありません。

レシート書式・傾き・影・折れ・省略商品名などで誤読することがあります。登録前にピンクの要確認カードと「商品合計 = 実支払額」を確認してください。
