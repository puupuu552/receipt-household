# 生活費レシート管理 PWA v1.4.2

iPhone / Android のブラウザ・ホーム画面PWAで使う、端末内保存型の生活費レシート管理アプリです。

## v1.4.2 の変更

- 差額だけを理由に、存在しない商品を新規作成する処理を廃止しました。
- OCR上に実在する「価格なしの商品行」が価格付き商品に挟まれている場合だけ、小計差額を仮価格として付けます（要確認）。
- 税区分や合計が曖昧な場合は、明細金額を勝手に按分して帳尻合わせしません。
- 小計・商品数・明細合計が矛盾した場合は警告し、人に確認してもらいます。
- 購入日・店舗名・商品名・税込計上額・実支払額に「×」全消去ボタンを追加しました。少し直す場合は従来どおり入力欄へカーソルを置いて編集できます。


## OCRについて

OCRはTesseract.jsを使用し、文字認識処理は端末側で実行します。初回はOCRエンジンと言語データの読み込みに通信を使います。

ローカルOCRのため、商品名が大きく崩れた項目は「要確認」のまま残ります。金額合計とピンクのカードを確認してから登録してください。

## 更新について

現在バージョンは `app.js` のURLクエリから取得します。更新ボタンはアプリ用Cache StorageとService Workerを更新しますが、IndexedDBの家計データは削除しません。
