# 生活費レシート管理 PWA v1.3.5

iPhone / Android のブラウザ・ホーム画面PWAで使う、端末内保存型の生活費レシート管理アプリです。

## v1.3.5 の変更
- OCRを2回実行して、レイアウト重視画像と白黒二値化画像の結果を比較
- 内税レシートで「小計 + 内税」を二重加算しないよう修正
- 「小計 2点」のような商品点数を利用
- 価格列だけOCRで欠けた商品が1件なら、小計との差額から金額を補完して「要確認」にする
- 2回のOCR結果を、日付・店舗・小計・商品数・合計整合性で採点して良い方を採用
- 画像そのものはIndexedDBに保存しない

## OCRについて
OCRはTesseract.jsを使用し、文字認識処理は端末側で実行します。初回はOCRエンジンと言語データの読み込みに通信を使います。

ローカルOCRのため、商品名の誤読は残ることがあります。ピンクの「要確認」カードと「商品合計 = 実支払額」を確認してから登録してください。
